#### **a. Unique Customers Visited Website**

```sql
SELECT COUNT(DISTINCT customer_id) AS unique_customers
FROM web_logs;
```

---

#### **b. Product Category with Highest Revenue**

```sql
SELECT category, SUM(total_sales) AS revenue
FROM product_data
JOIN (
    SELECT product_id, SUM(quantity * price) AS total_sales
    FROM web_logs
    GROUP BY product_id
) AS web_sales
ON product_data.product_id = web_sales.product_id
GROUP BY category
ORDER BY revenue DESC
LIMIT 1;
```

---

#### **c. Top 10 Customers by Total Spending**

```sql
SELECT 
    c.customer_id,
    c.first_name,
    c.last_name,
    SUM(w.quantity * p.price) AS total_spending
FROM customer_data c
JOIN web_logs w ON c.customer_id = w.customer_id
JOIN product_data p ON w.product_id = p.product_id
GROUP BY c.customer_id, c.first_name, c.last_name
ORDER BY total_spending DESC
LIMIT 10;
```
