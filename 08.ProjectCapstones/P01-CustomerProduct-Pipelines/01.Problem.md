## **E-Commerce Data Processing and Analytics Pipeline Using Azure Databricks and Spark SQL**

---

## **Problem Statement (Total Marks: 1000)**

---

### **Concept**

End-to-End Data Engineering and Insights Pipeline for TechCo: Ingestion, Transformation, and Analysis with Azure Databricks

---

### **Scenario**

You work as a data engineer for a fictional e-commerce company called "TechCo." TechCo collects large amounts of data from various sources, including web logs, customer interactions, and product information. Your task is to ingest, process, and transform this data using Azure Databricks to derive valuable insights.

---

## **Requirements and Marks Distribution**

### **1. Data Ingestion — 250 Marks**

Use Azure Databricks to ingest the provided dataset into your workspace. The dataset contains the following files:

* **web_logs.json**: Web logs containing user interactions with the website
* **customer_data.csv**: Customer information with columns: customer_id, first_name, last_name, email, phone
* **product_data.csv**: Product information with columns: product_id, product_name, category, price

---

### **2. Data Transformation — 300 Marks**

Perform the following transformations:

* Clean and preprocess web logs data (remove duplicates, handle missing values, etc.)
* Calculate total sales for each product based on order quantity and product price
* Join web logs data with customer and product information to create a unified dataset

---

### **3. Data Analysis — 300 Marks**

Using Spark SQL or DataFrame APIs, answer the following:

* How many unique customers visited the website?
* Which product category generated the highest revenue?
* Identify the top 10 customers based on total spending

---

### **4. Data Visualization — 150 Marks**

Create visualizations using Python libraries such as **Matplotlib** or **Seaborn**:

* Bar chart for revenue by product category
* Bar chart for top 10 customers by spending
